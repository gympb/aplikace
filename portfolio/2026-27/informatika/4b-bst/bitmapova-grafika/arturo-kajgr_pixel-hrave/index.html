Vyzkoušej, jak počítač ukládá obrázky. Za úkoly sbíráš body a postupuješ na vyšší úroveň.

🎨 Pixelová dílna

Obrázek je jen mřížka barevných čtverečků. Maluj tažením a sleduj, kolik paměti zabírá.

Skutečná velikost

Zkus mřížku 16: počet pixelů vzroste víc než dvojnásobně, ale obrázek je detailnější.

🌈 Míchání barev (RGB)

Každý pixel svítí červeně, zeleně a modře. Smíchej barvu, nebo zkus trefit zadanou.

Cíl ❓
Tvoje

Barva v počítači je 3 čísla od 0 do 255. Číslo má 8 bitů:

3 kanály × 8 bitů = 24 bitů
2²⁴ = 256 · 256 · 256 = 16 777 216 barev

🔢 Bity

Klikej na bity a zapínej je. Každý má váhu dvojnásobku toho napravo.

Se znaménkem (two’s complement): . Zkus 255 + 1 nebo × 2: čísla se přetečou.

8 bitů = 2⁸ = 256 hodnot (0 až 255). Proto je jeden barevný kanál v rozsahu 0–255.

📦 Kolik to zabere?

Velikost nekomprimovaného obrázku = šířka × výška × bity na pixel ÷ 8.

🗜️ Komprese RLE

Počítač umí opakování zkrátit. Napiš písmena (každé = jeden pixel) a uvidíš, jak se to sbalí.

Zkus „ABCDEFGH“: RLE tady nepomůže. Proto fotky (samý šum) potřebují jiné metody, třeba JPEG.

📺 Displej a palce

1″ = 25,4 mm. PPI říká, kolik pixelů se vejde na palec.

PPI = √(šířka² + výška²) ÷ úhlopříčka. DPI je stejný pojem pro tisk.

🧬 Obraz v paměti

Počítač obrázek „nevidí“. Má jen dlouhou řadu bajtů: pro každý pixel R, G, B a A (průhlednost). Klikni na pixel a podívej se, kde v paměti leží.

offset = y · délka řádku + x · kanály

Délka řádku = šířka · kanály. Zapni zarovnání a uvidíš výplň (průhledné bajty), jakou používá třeba BMP.

Celá paměť obrázku (96 bajtů, hex)

Totéž v kódu

const w = 6;
function setPixel(data, x, y, r, g, b) {
  const i = (y * w + x) * 4;   // 1) kde pixel začíná
  data[i]     = r;             // 2) červená
  data[i + 1] = g;             // 3) zelená
  data[i + 2] = b;             // 4) modrá
  data[i + 3] = 255;           // 5) plně neprůhledný
}

1) Přeskočíme y celých řádků a x pixelů, každý má 4 bajty. 2–4) Kanály leží hned za sebou. 5) Alfa 255 = nic neprosvítá.
