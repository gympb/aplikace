Co je to Rastrová Grafika?

Bitmapa / Rastr

Obrázek je tvořen **pravidelnou mřížkou čtverečků** (pixelů). Každý pixel má přesně definovanou polohu a barvu. Při přiblížení dochází k tzv. pixelizaci (vidíme jednotlivé kostičky).

Pixel (Picture Element)

Nejmenší samostatný prvek digitálního obrazu. Má jedinou barvu. Sloučením tisíců až milionů pixelů vzniká celkový detailní obraz (např. fotografie).

Rozlišení (Resolution)

Udává **počet pixelů na šířku a výšku** (např. 1920 × 1080). Čím více pixelů obrázek má, tím je detailnější.

Porovnání Formátů Rastrových Souborů

Různé formáty využívají různé typy komprese (ztrátová vs. neztrátová) a podporují různé vlastnosti jako je průhlednost nebo animace.

Ztrátová Komprese (Lossy Compression)

Algoritmus **trvale vymaže část obrazových dat**, která nejsou pro lidské oko tolik nápadná (např. velmi jemné odstíny barev v ploše). Výsledný soubor je **mnohonásobně menší**, ale při opakovaném ukládání dochází ke ztrátě kvality.

Typické použití: Fotografie na webu, sociální sítě (JPEG, WebP).
Neztrátová Komprese (Lossless Compression)

Obrázek se zmenší chytrým zakódováním dat (např. *„100 bílých pixelů za sebou“* místo ukládání každého zvlášť), ale **žádný pixel se neztratí**. Kvalita zůstává 100% zachována, ale výsledný soubor bývá větší než u ztrátové komprese.

Typické použití: Loga, ikony, grafika s textem, screenshoty (PNG, GIF).
JPEG / JPG Ztrátový

Nejpoužívanější formát pro digitální fotografie. Zmenšuje soubor vypuštěním detailů, které jsou pro lidské oko méně viditelné.

Komprese:Ztrátová
Průhlednost:NE
Animace:NE
Použití:Fotografie, Web
PNG Neztrátový

Ideální pro webovou grafiku, loga a ikony. Podporuje plnou průhlednost (Alpha kanál).

Komprese:Neztrátová
Průhlednost:ANO (Alpha)
Animace:NE
Použití:Loga, Grafika, Web
GIF Max 256 barev

Formát známý pro podporu jednoduchých animací. Omezen na maximálně 256 barev (8 bitů).

Komprese:Neztrátová
Průhlednost:ANO (1-bit)
Animace:ANO
Použití:Krátké animace, Memes
WebP Moderní Web

Moderní formát vyvinutý společností Google. Nabízí vynikající kompresi a nahrazuje JPG i PNG.

Komprese:Ztrátová i Neztrátová
Průhlednost:ANO
Animace:ANO
Použití:Moderní webové stránky
RAW Surová data

"Digitální negativ". Obsahuje přímá, nezpracovaná data ze snímače fotoaparátu s vysokou barevnou hloubkou.

Komprese:Žádná / Neztrátová
Průhlednost:NE
Animace:NE
Použití:Profesionální Fotografie
BMP Bez komprese

Standardní bitmapový formát operačního systému Windows. Nepoužívá kompresi, soubory jsou velké.

Komprese:Žádná
Průhlednost:NE
Animace:NE
Použití:Základní grafika Windows
